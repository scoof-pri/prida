# Uploading PRIDA to CrazyGames

Checked against the official documentation on 17 September 2026.

1. Sign in to the [CrazyGames Developer Portal](https://developer.crazygames.com/) and choose **Submit a game**. Enter the name **PRIDA**, an English description and controls. Choose the HTML5/WebGL build flow.
2. Upload the release client ZIP. It contains `index.html` at the root, `assets/`, `models/`, `icons/` and license notices. Do not upload the source project or `server.mjs` as the browser entry point. Keep all file paths relative. See [technical requirements](https://docs.crazygames.com/requirements/technical/).
3. Set supported platforms honestly. This build has keyboard/mouse and touch controls, but mobile support should be declared after testing on real devices. Landscape is the intended orientation.
4. Use the portal's Preview / QA tool before submitting. Verify loading, pointer lock, all seventeen weapons including melee, the jetpack and glider, touch look and firing, pause/resume, the shop, saves after reload, the shrinking zone, victory/defeat and sound after returning from another app. Test with cheats off. The built-in code `250886` is for solo debugging; online play ignores it.
5. Under progress saving, select **Yes, using the Data Module from the CrazyGames SDK** if using this build's portal saving. Check saving in the actual portal; the Data module is disabled if the submission toggle is not enabled. See [Data module](https://docs.crazygames.com/sdk/data/).
6. Supply three PRIDA covers: landscape **1920 × 1080**, portrait **800 × 1200**, square **800 × 800**. Prepare silent gameplay previews, up to **15–20 seconds**, at most **50 MB**, in the landscape and portrait formats requested by the portal. Covers/video are not included in the game ZIP. See [cover and video requirements](https://docs.crazygames.com/requirements/game-covers/).
7. For online groups, first deploy the included Node server behind WSS. Set its public address in `public/config.json`, then rebuild and upload the updated client ZIP. CrazyGames game-file hosting does not run this Node server. Verify invites with two separate devices/accounts and declare the lobby size as **10**. See [multiplayer requirements](https://docs.crazygames.com/requirements/multiplayer/).
8. Submit after completing Preview checks. Submission is reviewed; uploading does not mean the game has been accepted. Basic Launch can use an optional SDK and has no monetization. Full Launch requires the applicable full integrations and further QA. See [launch process](https://docs.crazygames.com/) and [requirements overview](https://docs.crazygames.com/requirements/intro/).

Technical limits currently include an initial download of at most 50 MB, at most 20 MB for mobile-homepage eligibility, at most 250 MB total with SDK, and at most 1,500 files. Without SDK the total must fit the initial-size limit. PRIDA's bundled client is approximately 10 MB uncompressed; check the actual upload report because ZIP size alone is not the initial download measurement.

The supplied build has no external advertising, real-money purchases or paid loot. Cosmetics use earned coins. Its Data and multiplayer SDK adapters still need actual portal verification, including switching between guest and logged-in accounts. Do not describe it as certified or fully reviewed before those checks and CrazyGames approval.
